# Projects

Personal coding projects you're building to practice or apply what's across this vault's topics —
lighter-weight than a [[Case-Studies|Case Study]], which is a full investigation of someone else's
project rather than something you're building. Shared across every topic. Created from
[[New-Project-Note]].

```dataview
TABLE repo AS "Repo", topics AS "Topics", status AS "Status", started AS "Started"
FROM #project
SORT status ASC, started DESC
```

> [!info] Requires Dataview
> See the setup notes in [[Home]].
