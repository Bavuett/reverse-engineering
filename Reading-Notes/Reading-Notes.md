# Reading Notes

Notes tracking books, courses, papers, and RFCs as you work through them. Shared across every
topic in this vault. Created from [[New-Reading-Note]].

```dataview
TABLE author AS "Author", type AS "Type", status AS "Status", topics AS "Topics"
FROM #reading-note
SORT status ASC, file.name ASC
```
