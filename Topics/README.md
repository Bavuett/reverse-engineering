# Topics/

One subfolder per subject you're studying, e.g. `Topics/Rust/`, `Topics/Reverse-Engineering/`.
Empty at ship time — add your first topic with the `New-Topic` Templater template (see
[[New-Topic]] / `Templates/New-Topic.md`), then finish scaffolding it from `_Topic-Skeleton/`.
See `CLAUDE.md` → "Adding a new topic" for the full walkthrough.

Each topic is a self-contained mini-vault with its own numbered chapters, `Reference`,
`Case-Studies`, `Cheatsheets`, `Tools`, `Reading-Notes`, and `Projects` — see `Home.md` for the
internal shape every topic follows.
